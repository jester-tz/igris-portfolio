IGRIS FINAL V5

This build uses the uploaded igris-human-redesign.zip as the visual baseline.
The homepage title, marketing copy, typography direction, and header were preserved
from that version.

Added/fixed:
- Light mode is the first-time/default theme; dark mode is optional and remembered.
- Deep red accent.
- Inter / Roboto / Arial / Poppins font stack.
- Work image full-screen preview.
- Classic subtle ID-card portrait treatment on About.
- Pixel & Proof clickable cards with floating Live Web-Work previews.
- Escape/outside-click/close-button support for overlays.
- Responsive navigation and reduced-motion fallback.
